# 🎮 Game Tracker API

REST API для учёта коллекции видеоигр, написанный на FastAPI и SQLAlchemy. Поддерживает полный CRUD, фильтрацию и сбор статистики.

## 🛠 Стек технологий
- **Фреймворк:** FastAPI
- **База данных:** SQLite + SQLAlchemy 2.0 (Async)
- **Валидация данных:** Pydantic v2
- **Тестирование:** pytest, httpx (AsyncClient)
- **Язык:** Python 3.11+

## ✨ Возможности
- Создание, чтение, обновление и удаление игр.
- Фильтрация игр по статусу (`backlog`, `playing`, `completed`, `dropped`) и платформе.
- Сбор статистики (суммарные часы, средний рейтинг, количество игр по статусам).
- Валидация входных данных (например, рейтинг строго от 1 до 10).
- Полностью асинхронная работа с базой данных.
- Покрытие тестами всех эндпоинтов (9 тестов, 100% успешных).
