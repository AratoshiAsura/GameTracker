# 🎮 Game Tracker API

REST API для учёта коллекции видеоигр, написанный на FastAPI и SQLAlchemy. Поддерживает полный CRUD, фильтрацию и сбор статистики.

## 🛠 Стек технологий
- **Фреймворк:** FastAPI
- **База данных:** SQLite + SQLAlchemy 2.0 (Async)
- **Валидация данных:** Pydantic v2
- **Тестирование:** pytest, httpx (AsyncClient)
- **Язык:** Python 3.11+

## ✨ Возможности
- Создание, чтение, обновление и удаление игр.
- Фильтрация игр по статусу (`backlog`, `playing`, `completed`, `dropped`) и платформе.
- Сбор статистики (суммарные часы, средний рейтинг, количество игр по статусам).
- Валидация входных данных (например, рейтинг строго от 1 до 10).
- Полностью асинхронная работа с базой данных.
- Покрытие тестами всех эндпоинтов.

## 🚀 Запуск проекта

### Требования
- Python 3.11 или выше
- `pip` и `venv`

### Установка и запуск

1. **Клонируй репозиторий:**
   ```bash
   git clone https://github.com/AratoshiAsura/GameTracker.git
   cd GameTracker
   ```

2. **Создай и активируй виртуальное окружение:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS
   .venv\Scripts\activate     # Для Windows
   ```

3. **Установи зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запусти приложение:**
   ```bash
   uvicorn main:app --reload
   ```

5. **Открой интерактивную документацию:**
   Перейди по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs), чтобы протестировать эндпоинты через Swagger UI.

## 🧪 Запуск тестов
Проект содержит тесты, покрывающие все эндпоинты и логику валидации. Чтобы запустить их:

```bash
pytest -v
```

## 📡 Эндпоинты API

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| **GET** | `/health` | Проверка работоспособности сервиса |
| **GET** | `/games` | Список всех игр (поддерживает фильтры `?status=` и `?platform=`) |
| **POST** | `/games` | Добавление новой игры |
| **GET** | `/games/{id}` | Получение конкретной игры по ID |
| **PATCH** | `/games/{id}` | Обновление данных игры |
| **DELETE** | `/games/{id}` | Удаление игры |
| **GET** | `/stats` | Получение статистики коллекции |
